# CI/CD Student Project

![CI Status](https://github.com/lerashlyz-cpu/ci-cd-student-project/actions/workflows/ci.yml/badge.svg)

Простой проект для демонстрации CI/CD pipeline с автоматическим тестированием.

## Функционал
- Калькулятор с операциями: +, -, *, /, **
- Автоматическое тестирование на Python 3.8, 3.9, 3.10
- Линтинг кода (flake8)
- Проверка безопасности (bandit)
